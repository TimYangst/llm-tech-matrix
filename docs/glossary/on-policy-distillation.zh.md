# On-Policy Distillation (OPD，在策略蒸馏)

> English: [on-policy-distillation.md](./on-policy-distillation.md)

**Slug:** `on-policy-distillation`
**类别：** alignment
**一句话概括：** 让单个统一的学生模型在自己采样的轨迹（"在策略"）上最小化对一组教师专家模型的反向 KL，从而把按领域训练的多个专家整合进一个模型；通常作为 specialist 训练之后的合并步骤。
**首次提出：** [Gu et al., 2024 — On-Policy Distillation of Language Models](https://arxiv.org/abs/2306.13649)；规模化与改进见 [Lu and Lab, 2025](https://arxiv.org/abs/2502.04428) 与 DeepSeek-V4 论文第 5.1.2 节。

## 概述

标准知识蒸馏（Hinton et al., 2015）让学生在固定数据集上对齐教师 logits。**在策略蒸馏**改为：训练轨迹由*学生自身*采样，再让学生在这些轨迹上去匹配教师。这样蒸馏信号与学生推理时实际生成的内容对齐，避免了 vanilla 蒸馏在学生分布偏离数据分布时出现的 off-policy 漂移。

`N` 个教师专家 `{π_E_1, ..., π_E_N}` 的目标函数：

`L_OPD(θ) = Σ_i w_i · D_KL( π_θ ∥ π_E_i )`

其中 `π_θ` 是学生，`w_i` 是各教师权重，反向 KL 在学生采样的轨迹上计算。反向 KL（相对于正向 KL）会惩罚学生在教师概率低的位置放置质量——鼓励学生集中在教师真正一致的区域。

DeepSeek-V4 把 OPD 用作**后训练的最终一步**，将 `>10` 个领域专家（数学 / 代码 / Agent / 指令跟随 / ...）整合进一个统一模型——取代 V3.2 在该位置使用的 mixed-RL 阶段。学生采样轨迹；对每条轨迹，相关领域教师的反向 KL 损失被计算并聚合。物理上分散于不同专家权重中的知识通过 logits 层面的对齐被整合到统一的参数空间，规避了权重合并或 mixed-RL 策略的性能退化。

V4 选用**全词表 logit 蒸馏**，而非早期工作里方差较大的 token 级 KL 估计——开销更高，但梯度更稳定。为在大规模上可行：（1）教师权重存于集中式分布式存储，按需以 ZeRO 风格分片加载；（2）教师前向只缓存最后一层隐藏状态，logits 在用时通过预测头即时重建；（3）样本按教师索引排序分发，每个 mini-batch 中显存里至多驻留一个教师 head；（4）KL kernel 用 TileLang 自定义实现。

## 使用此技术的模型

| 模型              | 变体 / 细节                                                                                                                                                                                                                                            |
| ----------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| DeepSeek-V4-Pro   | 多教师 OPD，整合 >10 个领域专家（数学 / 代码 / Agent / 指令跟随 / ...）。全词表 logit 蒸馏（非 token 级）。集中式 ZeRO 分片教师存储；最后一层隐藏状态缓存 + 即时 logit 重建；样本按教师索引排序分发。取代 DeepSeek-V3.2 在该位置使用的 mixed-RL 阶段。 |
| DeepSeek-V4-Flash | OPD 配方与 V4-Pro 完全相同（同一家族的训练流水线）。学生与教师参数预算更小，但工程实现一致——学生为 V4-Flash，教师为 >10 个 V4-Flash 专家。                                                                                                             |
