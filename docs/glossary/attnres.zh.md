# Attention Residuals (AttnRes)

> English: [attnres.md](./attnres.md)

**Slug:** `attnres`
**类别：** residual connections
**一句话概括：** 把残差流沿深度的"均匀累加"换成**对深度做注意力** —— 每一层用一个可学习的伪 query，有选择地从此前所有层的表示中检索信息。
**首次提出：** [Attention Residuals（Kimi Team, 2026）](https://arxiv.org/abs/2603.15031)；在 [Kimi K3 技术报告 §2.2](https://arxiv.org/abs/2607.24653) 中被大规模部署。

## 概述

标准残差连接把网络此前算出的一切压缩进单一状态 `h_l` —— AttnRes 论文明确把这个瓶颈类比为"沿时间的 RNN"。
而 Transformer 早已在*序列*轴上解决过同样的问题：用注意力取代递推。AttnRes 把这一招搬到*深度*轴上。

每一层 `l` 持有一个**可学习的伪 query** `q_l = w_l ∈ R^d`（逐层静态）。key 与 value 则是此前所有层的实际输出，
并把 token embedding 作为第 0 号来源，保证它始终可达：

```
α_{i→l} = φ(q_l, k_i) / Σ_j φ(q_l, k_j),   φ(q,k) = exp(qᵀ · RMSNorm(k))
h_l = Σ_{i<l} α_{i→l} · v_i
```

对 key 做 RMSNorm 是关键：否则输出幅值大的层会不论相关性如何都主导深度注意力权重。
注意：虽然 query 是静态的，但权重通过 key 依赖输入 —— 所以来源选择**确实是动态的**。

**真正上线的是 Block AttnRes。** 完整版 AttnRes 的算术开销是 O(L²d)（L < 100 时可接受），
但需要 O(Ld) 的显存与跨流水段通信来保活每一层输出。分块版把 L 层切成 N 块；块内各层输出求和成一个块表示
`b_n`（`b_0` 为 token embedding），跨块只在这 N 个块级表示上做完整注意力 —— 第 n 块的首层看到
`[b_0 … b_{n−1}]`，后续层再额外看到块内的滚动部分和。显存与通信从 O(Ld) 降到 O(Nd)，
推理期状态被限定，且并行的跨块结果可通过 online softmax 与顺序的块内部分和合并。
论文报告 N ≈ 8 在各规模上就能拿到大部分收益。

与 [mHC](./mhc.zh.md) —— 2025 年后另一条改造残差流的路线 —— 对比很有意思：mHC 把残差流**加宽**到
`R^{n_hc × d}` 并把层间映射约束到双随机矩阵；AttnRes 则保持宽度 `d` 不变，转而让**读取哪些前序层**依赖数据。
两者都源自"残差连接是瓶颈"的判断，却给出了不同答案。

## 使用此技术的模型

| 模型    | 变体 / 细节                                                                                                                                                                                                                                                                                                                                 |
| ------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Kimi K3 | 93 层上使用块大小为 12 的 Block AttnRes（`config.attn_res_block_size=12`）—— 论文描述为 8 块且最后一块不完整，算上 embedding 层共 9 个来源。最终输出层聚合全部 N 个块表示。它还向下游延伸：EAGLE-3 草稿模型的输入融合了取自**第 1、第 4 与最后一个 AttnRes 块**输出的低/中/高层特征（§4.1.4），因此块结构同时充当了投机解码的特征抽取接口。 |
