# 门控残差（Gated Residual, GR）

> English: [gated-residual.md](./gated-residual.md)

**Slug:** `gated-residual`
**类别：** other
**一句话概括：** 把残差流加宽为 4 条并行分支，用逐元素、数据相关的 sigmoid 门去读、用每分支一个标量去写，并且把 Hyper-Connections 的分支间混合矩阵整个删掉。

**首次提出：** [On the Design of Qwen3.8-Next Architecture（Qwen Team, 2026）](https://github.com/QwenLM/Qwen3.8-Flash-Next/blob/main/tech_report.pdf) §2.2

## 概述

前置归一化让深层 transformer 能稳定训练，但也削弱了每一层实际读到的信号：所有 block 读的是同一条流，于是早期写入的特征必须和之后写入的一切竞争。已有两类解法——让每层的*读和写*更有表达力（highway 网络），或者把*流本身加宽*成若干并行分支（AltUp、[Hyper-Connections](./mhc.zh.md)）。GR 的前提是这两者互补：加宽提供容量，更强的读决定这些容量怎么花。

GR 保留 `n_r = 4` 条分支，然后逐项去问「多加的表达力到底值不值」。消融给出的答案相当干净，也正是 GR 与 HC/mHC 分道扬镳的地方：

- **读的粒度重要，写的粒度不重要。** 把读从「每分支一个标量」细化到「每分支每通道一个权重」有收益；对写做同样的细化则「几乎没有任何收益」。因此 GR 的读是逐元素的，写仍是每分支一个标量。
- **`H_res` 不值。** 一旦读和写足够有表达力，那个 `n_r × n_r` 的分支间混合算子——HC 把容量投在它上面、mHC 还进一步把它约束到双随机矩阵流形上——「不带来显著改进」。GR 直接删掉它。这既省掉了每个 block 对残差状态的一次完整读取（加宽残差流在推理侧的主要开销），也去掉了一个需要额外约束、因而可能带来不稳定的来源。没有混合算子之后分支彼此独立，信息流也更容易分析。
- **有界正门优于 tanh**，在 loss 和稳定性上都是——这和 GDN、注意力输出门上的结论一致。
- **读取所有分支**，且各自单独归一化（对加宽后的流做 group RMSNorm），而不是先池化、也不是只读最后一条分支。

消融最后收敛出来的这个「读」，恰好就是 *GatedNorm*——RMSNorm 之后一个轻量的逐元素自门控，在另一项工作中被发现能显著改善训练稳定性——作用在加宽后的流上。Qwen 把两者合并，名字也由此而来。因为这个读已经完成了归一化和门控，**GR 是替代掉 block 的前置归一化**，而不是加在它前面，所以加宽残差流没有引入任何新的 norm 层。

稳定性上的后果是这个设计的目的，而不是副作用。在把学习率拉到最优值 4 倍的压力测试下，上一代结构频繁出现 spike，而 GR 配方全程稳定；把门控单独拿出来做单变量对照，确认它是稳定性余量的关键贡献者。Qwen 报告全量训练全程没有一次 loss spike，且**没有用 qk-clip 也没有用 SwiGLU-clip**——那是其他厂商依赖的显式裁剪拐杖。而这份稳定性余量随后是被*花掉*的：正是它让重新拟合的 scaling law 敢于推荐更大的学习率和 batch size。

## 使用此技术的模型

| 模型               | 变体 / 细节                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                            |
| ------------------ | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Qwen3.8-Flash-Next | `n_r = 4` 条分支（`hc_count=4`），低秩瓶颈 `d/8 = 320`（`hc_lowrank=320`），**每一层的注意力 block 和 MLP block 各有一个独立的 GR 模块**。读：每分支带独立 gain 的 RMSNorm → 从所有分支预测出的逐元素 sigmoid 门 → 门控后分支求均值。写：`s = 2·σ(W_w vec(R̂))`，每分支一个标量。没有静态项，也不需要特殊初始化。25B-A3B / 560B token 上的消融：pre-norm 1.617 loss / 50.91 均分 → mHC 静态 1.596 / 52.49 → mHC 动态 1.594 / 54.47 → **GR 1.590 / 54.66**。推理时残差状态支持 FP8 存储，以抑制 4 条分支带来的访存开销。 |

## 相关技术

- [mHC / Hyper-Connections](./mhc.zh.md) —— 同一家族。HC 和 mHC 保持标量读写、把容量投在 `H_res` 上；GR 把容量投在读上并删掉 `H_res`。在 25B-A3B 规模上两者质量相当，GR 赢在效率和稳定性。
- [AttnRes](./attnres.zh.md) —— Kimi K3 的另一条路线，用对更早层输出做 softmax 注意力来形成每个子层的读。28 层规模下正面对比：完整 AttnRes 到 1.762 loss，GR（`n_r=4`）同样是 1.762。
- [Muon](./muon.zh.md) —— GR 的两个低秩投影被刻意排除在 Muon 之外、留在 AdamW 上，原因是它们的形状过于狭长。
